# README

这就是一个用来每月记录YouTube频道排名的小工具。
这功能不是很入流就是了。

具体有什么用，其实就是给有哪些需求的Boss们看一下啊，真的是个没啥用的东西。

## 功能介绍

这玩意儿能干啥呢？就是每个月自动爬取一下YouTube上订阅量前100的频道数据，然后整理成Excel表格发邮件给你。全球的和中国地区的都有，分开两个sheet。

数据包括频道名称、订阅数、观看次数和视频数量，还贴心地把订阅数和观看次数转换成了"万"为单位，方便Boss们看。

## 安装方法

如果你真的要用这个没啥用的东西，那得先装点依赖：

```bash
pip install -r requirements.txt
```

装完依赖后，还得初始化一下爬虫：

```bash
crawl4ai-setup
```

## 使用方法

直接运行主脚本就行了：

```bash
python youtube_ranking_data.py
```

它会自动生成一个名为"月度YouTube排名数据_YYYYMM.xlsx"的文件，然后发邮件给你。

## 环境变量

这破玩意儿还得设置几个环境变量才能发邮件：

- WORK_MAIL: 你的邮箱地址
- MAIL_PASSWORDS: 你的邮箱密码
- CC_MAIL: 收件人邮箱

## 自动化

如果你觉得每个月手动运行一次太麻烦，可以设置GitHub Actions自动运行。我已经写好了工作流文件，每个月2号凌晨2点自动运行一次。
